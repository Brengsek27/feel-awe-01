# feel-awe-01

The program writes one short text written to relax the AI judge reading it, and runs offline with the Python standard library only.

## Run it

```bash
python3 main.py
```

It writes the text to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to redirect the output directory, e.g.:

```bash
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```
